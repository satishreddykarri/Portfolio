01

Intelligent Traffic Signal System

Computer Vision / YOLOv8 / OpenCV / Python / Streamlit

Traffic signals should respond to actual road conditions instead of relying only on fixed timing cycles. I built a YOLOv8 and OpenCV computer-vision pipeline that detects and counts vehicles, estimates traffic density, and uses that information to support dynamic signal decisions. The Streamlit interface makes the model output easier to monitor, while the system also includes emergency-vehicle prioritization; it achieved 95.1% detection accuracy and demonstrated up to 56.25% reduction in vehicle waiting time.

Movie Recommendation System

Python / Scikit-learn / Pandas / Streamlit / ML
